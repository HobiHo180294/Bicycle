## 🤖 Introduction

Welcome to the future of bicycle commerce — a dynamic marketplace designed to connect riders, retailers, and bike lovers in one seamless experience. Whether you're searching for your next road companion or looking to sell a trusted two-wheeler, our platform makes it fast, secure, and exciting to explore the world of cycling.

🔧 _This is an MVP version of the application — focused on showcasing core marketplace functionality such as listing, browsing, and purchasing bicycles._

## ⚙️ Tech Stack

- JavaScript (ES6+)
- Webpack – for bundling and development server
- Babel – for JavaScript transpilation
- Sass/SCSS – for styling
- PostCSS – with postcss-preset-env for CSS compatibility
- jQuery – DOM manipulation
- js-cookie – handling cookies
- ESLint + Prettier – for code linting and formatting
- HTML Webpack Plugin – for HTML template integration
- Image Optimization – via image-webpack-loader
- File & Style Loaders – (css-loader, style-loader, sass-loader, etc.)
- MiniCssExtractPlugin – for CSS extraction in production
- Terser & CSS Minimizer – for production optimization

## 🔋 Features

👉 **User Registration & Login:** Secure authentication system allowing users to register, log in, and manage sessions.

👉 **Product Listing:** Users can view a collection of vintage bicycles organized by category or filter criteria.

👉 **Add to Cart:** Buyers can add selected bikes to their shopping cart for later review or purchase.

👉 **Responsive UI:** Optimized design for seamless experience on both desktop and mobile devices.

👉 **Admin-Friendly Structure:** Easily extendable layout for future admin features like inventory management or order tracking.

👉 **Modular Codebase:** Clear separation of concerns and organized file structure for scalable development.

👉 **Asset Optimization:** Images and styles are optimized via Webpack plugins for faster page load.

👉 **ESLint + Prettier Integration:** Ensures clean, consistent code through automated linting and formatting tools.

👉 **SASS Styling:** Maintainable and scalable styles with support for variables, nesting, and media queries.

👉 **Browser Compatibility:** Supports all major browsers via Babel transpilation and PostCSS polyfills.

👉 **MVP Readiness:** Core functionality fully operational, including browsing and basic cart flow, ready for initial user feedback.

👉 **Static Deployment Support:** Webpack build creates a production-ready static site suitable for deployment on platforms like GitHub Pages or Netlify.

## 🤸 Quick Start

Follow these steps to set up the project locally on your machine.

### Prerequisites

Make sure you have the following installed on your machine:

- [Node.js](https://nodejs.org/en) ≥ **16.0.0**
- [npm](https://www.npmjs.com/) ≥ **8.0.0**
- [Git](https://git-scm.com/) ≥ **2.30.0**

### Cloning the Repository

```bash
git clone ...
cd Bicycle
```

### Installation

Install the project dependencies using npm:

```bash
npm install
```

### Running Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the project.

### Watching for Changes

```bash
npm run watch
```

### Running Production Mode Locally

```bash
npm start
```

### Creating Production Build

```bash
npm run prod
```

### Clearing Build Folder

```bash
npm run clear
```
